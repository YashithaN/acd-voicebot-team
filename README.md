# Academia AI Voice Bot (`acd_voicebot`)

Voice bot pipeline repository for SDE teams.

## SDE 5 Voicebot (W1: Audio and VAD)

Foundation audio pipeline developed by **Yashitha N** (Workstream W1).

### Quickstart

- **Run CLI Demo (single command):**
  ```bash
  python projects/sde-5-voicebot/cli_demo.py
  ```

- **Run Unit Tests (single command):**
  ```bash
  python -m unittest discover -s projects/sde-5-voicebot/tests -t projects/sde-5-voicebot
  ```

For detailed schema documentation, constraints, and architecture, see [`projects/sde-5-voicebot/README.md`](projects/sde-5-voicebot/README.md).
